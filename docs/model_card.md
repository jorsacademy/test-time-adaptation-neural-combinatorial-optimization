# Model Card

## Intended use

Research and teaching on test-time adaptation for small Euclidean TSP instances. The model is intended for controlled comparisons of inference-time compute allocation, not operational route planning.

## Model

A permutation-equivariant node encoder with symmetric pair scoring. It outputs static edge logits consumed by a masked autoregressive tour constructor.

## Training data

Synthetic exact-labeled Euclidean TSP instances generated by this repository. Default source sizes are 8, 10, and 12 nodes. The source model is supervised by exact optimal-tour edge indicators.

## Test-time adaptation

The recommended research method is `adapter_tta`, which updates only fresh per-instance residual embeddings, node biases, and a temperature scalar. Adaptation observes sampled-tour lengths but not exact optima.

## Limitations

- exact evaluation is exponential in node count;
- source data are synthetic;
- static edge logits omit richer autoregressive context;
- REINFORCE has high variance;
- no approximation guarantee;
- no calibrated uncertainty;
- no production latency or safety validation;
- no claim of superiority over LKH, Concorde, OR-Tools, or commercial solvers.

## Reliability controls

- hard visit masks;
- independent tour audits;
- best-so-far archive;
- source-model fingerprints;
- Safetensors checkpoints;
- finite-value and schema checks;
- exact Held–Karp comparison on supported sizes.
